# Лабораторная работа №2 — «Электрички»

Веб-приложение в духе «Прибывалки» для пригородных поездов (электричек): поиск станций, расписание по станции и между двумя станциями, избранное. Данные — через [API Яндекс.Расписаний](https://yandex.ru/dev/rasp/doc/ru/) (v3.0).

## Соответствие требованиям курса

| Требование | Как сделано |
|------------|-------------|
| Завершённое приложение с клиентом и сервером | **Frontend** (React + Vite) и **backend** (Node.js + Express): фронт ходит на свой JSON API, бэкенд проксирует запросы к Яндексу и кэширует справочник станций |
| Верстка HTML, CSS, адаптив | Разметка в компонентах React (достаточно тегов за счёт списков, форм, карты), стили в `frontend/src/styles/` (`main.css`, `adaptive.css`), медиазапросы для планшета/десктопа |
| jQuery или аналог | **React** как эквивалент по сложности UI |
| Динамическая подгрузка контента | Запросы к `/api/...` через `fetch`, состояние в компонентах |
| Изменение DOM и CSSOM | Обновление DOM через React; при необходимости — правки CSS-переменных/стилей (тема, glassmorphism) |

Задание по варианту см. раздел [«Вариант 2»](#вариант-2-аналог-прибывалки-для-электричек) ниже.

## Реализованный функционал

- **Поиск станции** по названию (запрос к локальному кэшу станций на бэкенде).
- **Карта** — Яндекс.Карты (`@pbe/react-yandex-maps`): маркеры станций, выбор станции кликом.
- **Расписание по станции** — электрички, проходящие через выбранную станцию (`/api/schedule/station`, тип транспорта `suburban`).
- **Маршрут между двумя станциями** — поиск рейсов (`/api/schedule/route` → метод `search` API Яндекса).
- **Избранное** — сохранение станций в `localStorage`, быстрый переход из вкладки «Избранное».
- **Адаптив** — интерфейс ориентирован на узкие экраны (Ant Design, брейкпоинты, компоновка списков и шапки).

## Архитектура

```
websec-2/
├── backend/          # Express, прокси к api.rasp.yandex.net, кэш stations_list
│   ├── server.js
│   └── stations-cache.js
└── frontend/         # React 19, Vite, Ant Design, React Router
    ├── src/
    │   ├── main.jsx          # точка входа, Router, тема Ant Design
    │   ├── App.jsx           # вкладки, маршруты
    │   ├── components/
    │   └── services/         # api.js, storage.js (избранное)
    └── public/               # статика (иконки, gif для пустого избранного и т.д.)
```

### Backend (порт по умолчанию `3001`)

| Маршрут | Назначение |
|---------|------------|
| `GET /api/search` | Поиск станций по строке `query`, опционально сортировка по `lat`/`lon`, лимит `limit` |
| `GET /api/schedule/station` | Расписание станции: `station` (код), опционально `date`, `direction` |
| `GET /api/schedule/route` | Рейсы между станциями: `from`, `to`, опционально `date` |

Кэш станций подгружается из `stations_list` API и сохраняется в `stations-cache.json` (при первом запуске).

### Frontend

| Компонент / файл | Роль |
|------------------|------|
| `App.jsx` | Вкладки «Станция / Маршрут / Избранное», маршрутизация (`/`, `/route`, `/favorites`, `/station/:code`) |
| `SearchBar.jsx` | Поиск, URL-параметры (`q`, `map`, `all`), карта, список результатов |
| `SearchOptions.jsx` | Кнопки: показать/скрыть карту, «все станции» |
| `StationMap.jsx` | Яндекс.Карты, маркеры, выбор станции |
| `StationResults.jsx` | Список найденных станций, звезда избранного |
| `Schedule.jsx` | Расписание выбранной станции, избранное |
| `RouteSearch.jsx` | Выбор «откуда / куда / дата», список рейсов |
| `Favorites.jsx` | Список избранных станций, пустое состояние |
| `services/api.js` | Обёртки над `fetch` к `/api/...` |
| `services/storage.js` | `localStorage` для избранного, событие `favorites:changed` |

В режиме разработки Vite проксирует `/api` на бэкенд (`vite.config.js` → `http://localhost:3001`).

## Переменные окружения

**Backend** — файл `backend/.env`:

```env
YANDEX_API_KEY=<ключ API Яндекс.Расписаний>
PORT=3001
```

**Frontend** — файл `frontend/.env`:

```env
VITE_YANDEX_MAPS_APIKEY=<ключ JavaScript API и Карт 2.1 для localhost>
```

Ключ карт должен быть выдан для домена разработки (например `http://localhost:5173`). Без него карта может показывать предупреждения в консоли.

## Установка и запуск

Требуется **Node.js** (рекомендуется LTS).

### 1. Backend

```bash
cd backend
npm install
npm run backend-start
```

Сервер слушает `http://localhost:3001` (или `PORT` из `.env`).

### 2. Frontend

В другом терминале:

```bash
cd frontend
npm install
npm run dev
```

Открой в браузере адрес из вывода Vite (обычно `http://localhost:5173`). Запросы к `/api` уходят на бэкенд через proxy.

### Сборка фронтенда для продакшена

```bash
cd frontend
npm run build
```

Артефакты в `frontend/dist/`. Для превью: `npm run preview`.
